# Speech English Tutor Webplugin

A Chrome extension that helps you learn English by reading selected text aloud using OpenAI's high-quality Text-to-Speech (TTS) and providing instant translations into Spanish.

## Features

- **High-Quality TTS**: Uses OpenAI's `gpt-4o-mini-tts` model for natural-sounding voiceovers.
- **Instant Translation**: Translates selected text into Spanish using OpenAI's `gpt-4o-mini` model.
- **Interactive Popup**: Displays translations in a clean, draggable, and modern-looking popup.
- **Context Menu Integration**: Simple "Speak selected text" option available on right-click.

## Architecture

- **Background Script**: Handles communication with OpenAI APIs (TTS and Chat Completion) and manages the offscreen document for audio playback.
- **Content Script**: Injects the translation popup into web pages and handles text selection positioning.
- **Offscreen Document**: Required by Chrome Extension Manifest V3 to play audio from the background service worker.
- **Vite**: Used as the build tool with `vite-plugin-web-extension` for a modern development experience.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- An [OpenAI API Key](https://platform.openai.com/api-keys)

## Setup

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd speech-english-tutor-webplugin
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Configure environment variables**:
    - Create a `.env` file in the root directory (you can use `.env.example` as a template).
    - Add your OpenAI API key:
      ```env
      VITE_OPENAI_API_KEY=your_actual_api_key_here
      ```

4.  **Build the extension**:
    - For development (with watch mode):
      ```bash
      npm run dev
      ```
    - For production:
      ```bash
      npm run build
      ```

## Installation in Chrome

1.  Open Chrome and navigate to `chrome://extensions/`.
2.  Enable **Developer mode** (toggle in the top right corner).
3.  Click **Load unpacked**.
4.  Select the `dist` folder generated by the build process.

## Usage

1.  Navigate to any website.
2.  Select the English text you want to hear and translate.
3.  Right-click and select **"Speak selected text"**.
4.  The extension will read the text aloud and show a translation popup near your selection.

## Tech Stack

- **OpenAI API**: For TTS (`gpt-4o-mini-tts`) and Translation (`gpt-4o-mini`).
- **Vite**: Build tool.
- **Manifest V3**: Latest Chrome Extension standard.
- **JavaScript (ES Modules)**: Modern JS syntax.
